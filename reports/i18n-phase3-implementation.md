# Sillage 外国人向け化 Phase 3 実装レポート

- 実装日: 2026-08-26
- 対象: Fragrance Database × Japan Store Database
- 公開前基準コミット: `e150cbb`

## 結論

英語商品数を25件のまま維持し、京都と東京を一つの店舗DBから生成する構造へ移行した。東京27店舗、京都18店舗の計45店舗を掲載し、個別商品の在庫を断定せず、公式情報でブランド取扱いを確認できた店舗だけを商品・ブランドから案内する。

大阪は東京ガイドの本番安定性を確認してから着手する。Phase 3では追加しない。

## 実装内容

### 共通店舗DB

- `data/stores.json` を唯一の店舗データ源とした。
- 旧 `data/kyoto-shops.json` と日英の京都オーバーレイを廃止した。
- 京都18店舗の件数、順番、座標、Google Maps URL、日本語記事の表示を維持した。
- 東京27店舗を公式ブランド・店舗情報から登録した。
- 店舗ごとに都市、エリア、日英名・住所、最寄り駅、営業時間、店舗種別、取扱ブランド、確認日、情報源を保持する。
- 英語対応・免税が公式確認できない場合は `null` とし、推測しない。
- 全店舗の取扱い状態は `brand-confirmed`。個別商品の在庫を意味しない。

### 店舗数

| 都市 | 店舗数 |
|---|---:|
| 東京 | 27 |
| 京都 | 18 |
| 合計 | 45 |

店舗種別は、ブランドブティック21、百貨店カウンター9、カスタムフレグランス6、複数ブランド専門店6、百貨店3。

### 英語ページ

- `/en/guides/perfume-shopping-tokyo/` を新設した。
- 東京ガイドはエリア別店舗、初回訪問向け導線、日本発ブランド、注意事項を掲載する。
- 京都ガイドを共通DB生成へ移行し、18店舗を維持した。
- 英語トップで東京、京都、日本発ブランド、英語商品を主要導線にした。
- 日本発ブランドガイドを4ブランドから6ブランドへ拡張した。
- 公式確認できる店舗がある英語商品14件に「Where to explore … in Japan」を追加した。
- 対応する英語ブランド詳細に「Where to Find … in Japan」を追加した。

## SEO・構造化データ

- 東京ガイドに一意なtitle、description、canonicalを設定した。
- `Article`、`BreadcrumbList`、27件の`ItemList`を出力した。
- 日本語版が存在しない東京ガイドには架空の`hreflang=ja`を出力しない。
- sitemapへ東京ガイドの正規URLを追加した。
- 商品・ブランド・店舗の主要情報は初期HTMLに含めた。

## 計測

既存GA4実装に次のイベントを追加した。既存の購入リンク計測は変更していない。

- `city_guide_view`
- `store_official_click`
- `store_map_click`

## 監査・検証

- 共通店舗DB検証: 45店舗、ID・Google Maps URL重複0件
- 東京ガイド: 27カード、ItemList 27件
- 京都ガイド: 18カード、ItemList 18件
- 店舗導線がある英語商品: 14/25件
- 日本発ブランドガイド: 6ブランド
- 外部リンク監査: 73 URL、`ok` 64、`redirect` 4、`blocked` 2、`timeout` 3、404/410は0件
- 403・429・timeoutはリンク切れと断定せず、要手動確認として扱う。
- JavaScript生成、サイト生成、既存14検証、新規店舗検証、`git diff --check`はすべて合格した。
- 375 / 768 / 1024 / 1440pxで東京・京都・英語トップ・商品・ブランドを確認し、横スクロールとコンソールエラーは検出されなかった。
- `focus-visible`と`prefers-reduced-motion`を生成HTMLと検証処理で確認した。

詳細なリンク結果は `reports/i18n-phase3-store-link-audit.csv`、移行前監査は `reports/i18n-phase3-store-schema-audit.md` を参照。

- 「Individual fragrance stock is not confirmed」と明示した。
- 日本語の商品データ150件、英語商品25件、公開URL、計測IDを変更していない。
- Google Maps埋め込みや新しい外部APIは追加していない。
