## 2. 公開前の要対応

### P1: LOEWE Agua Élの容量別リンクが商品に到達しない

- data/fragrances.json:13710,13726 / loewe-6 / 50・100mL。
- 保存した海外公式URLへ日本側からアクセスすると /int/ja_JP/ のトップへ転送。通常ブラウザでも再現。
- 容量別公式ボタンとしての役割を果たせない。修正案: 正しい現行の同一商品URLを確認できるまで容量別購入リンクを保留し、容量記録と根拠自体は別扱いにする。

### P1: 認証要求先が公式購入先として追加されている

- data/fragrances.json:4228 / carolina-herrera-1 / 50mL。
- alokai-prod.carolinaherrera.com の既存リンクを容量別へ再利用しているが、今回GETとWeb取得の両方で401。
- 404とは断定しないが、一般ユーザー向け購入先として確認できない。公開向け公式URLへ置き換えるか容量別ボタンを保留する必要がある。元の共通購入リンクにも存在した問題を今回引き継いでいる。

### P2: LOEWE Solo Cedro 100mLの転送先が「セット」表記

- data/fragrances.json:13627 / loewe-5。
- 日本向け転送先タイトルは「ロエベ ソロ セドロ セット 100ml」。単品ボトルとしての登録と一致するか、セット内容・地域差を要確認。HTTP 200だけでは合格にしない。

### P2: 容量別公式ボタンの計測が不完全

- build-items.mjs:557–564。容量パネルがhero-actionsではないため button_position が bottom になる。
- data-volume-ml は出力しているが読んでいない。初期の「すべての容量を見る」で100mLボタンを押すと容量がイベントに入らない。既存スクリプトをVMで実行して再現。
- 英語版は build-i18n.mjs と public/assets/analytics.js:74–77 の経路で official_click を送るが、容量情報・capacity位置を含まない。生HTMLの楽天38件だけは public/assets/size-picker.js がvolume_mlとcapacityを送るため、日英・購入先で不統一。
- 対処案: 購入ボタン自身の volume_ml と、ユーザーが選んだ requested_volume_ml を区別し、日英でcapacity位置を統一。共通リンクを容量一致済みと扱わない。

### P2: 容量の網羅性とボトル種別が不足

- aux-paradis-1 は15mLのみ。公式には15/30mLスプレーと60mLレフィル・スポイトを記載。30mLが不足している。
- 60mLを通常スプレーと同じ選択肢として追加すると誤解を招く。今の表示テンプレートは volumeMl が中心で、レフィル/スプレー/セットの違いを表示しない。
- 追加調査では濃度と容量に加えて容器・販売形態を区別する必要がある。今回は補完・設計変更はしていない。
- 根拠: [AUX PARADIS公式 フルール](https://www.auxparadis.com/products/210116.html)。

### P3: 表示上の改善点

- lib/size-picker.mjs:24。公式だけの容量パネルにもアフィリエイトを含む旨のPR文が毎回出る。Jo Maloneの初期表示では3回反復。
- lib/size-picker.mjs:21。英語版にも「楽天市場で価格を見る」が日本語のまま入り、lang=jaの外側指定や英語補足がない。正式HTMLは変更せず、周囲に英語の案内とlang指定を追加する方法が適切。
- 一般の購入ボタンは選択容量と非連動。注意書きはあるが、選択後も価格や一般楽天リンクは変わらないので、容量確定済みの購入ボタンと視覚的に区別することが望ましい。

## 3. 正常だった点

- 商品数・順序は維持。HEADとの差分は商品データのsizesのみで、説明・ノート・濃度・一般購入リンクを変更していない。
- もしも38件は保存済み正式HTML・SHA256・リンク・容量に全件一致。1×1インプレッション原文保持。
- 楽天38件の販売先を直接GETし、全件200。EUC-JPを正しく復号し、タイトルの商品名・容量を確認。不一致を認めず。在庫・出品者の信頼性の保証ではない。
- 容量選択、解除、選択容量だけの表示、未確定商品の案内が動作。
- ネイティブselectはキーボード操作でき、focus-visibleの枠を確認。
- 日本語210ページ・英語85ページの既存17検証すべて成功。git diff --check成功。
- これらの既存検証は外部商品の一致や計測値の正確さを保証しないため、上記問題を検知できていなかった。

## 4. 外部リンク確認

128URL: HTTP成功102、リダイレクト8、403ブロック17、401要確認1。404/410なし。

- 102件のHTTP成功にはCHANEL等のタイトルを取得できない応答もある。全容量の現行販売確認とはみなさない。
- 17件の403はアクセス制限。リンク切れと断定しない。
- Prada Intenseは直接GETのtitleがundefinedだが、Web取得で同一商品EDP100mLを確認。取得方法の差があるため一律不合格にしていない。オンライン販売の入荷待ち表記も確認。
- 詳細: fragrance-capacity-review-links.json。転送先URL・商品slug・容量・HTTP状態を記録。
- 自分の広告クリックは発生させず、楽天の販売先URLに直接アクセス。ローカルプレビューでもGA4通信・広告インプレッション通信を抑止。

## 6. 推奨する次の対応

1. 誤転送・認証要求の容量別購入先を先に修正/保留。
2. 日英の容量計測と表示の不統一を最小差分で修正し、回帰テスト追加。
3. AUX PARADIS等の不足容量を根拠付きで補完。レフィル/セットの区別を決める。
4. 403・内容未確認の公式リンクを優先して再確認してから公開判断。

90商品の容量別リンク未登録、10商品の容量未確定は残存。現段階で「全商品50/100mL対応完了」とは報告できない。
